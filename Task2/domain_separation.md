# Разделение системы на домены

## Домены системы

| Домен | Назначение | Бизнес-направление |
|-------|-----------|-------------------|
| **Медицинский домен** | Клиники, медицинские операции | Клиники |
| **Финтех домен** | Банковские и финансовые сервисы | Финтех-услуги |
| **AI домен** | ИИ-сервисы для работы с медицинскими данными | ИИ-сервисы |
| **Корпоративный домен** | Головной офис, HR, инвентаризация, финансовая отчётность | Головной офис |
| **Аналитический домен** | Витрина данных, BI, портал самообслуживания | Общий для всех |

## Обоснование разделения

**Принцип разделения**: Каждый домен соответствует отдельному бизнес-направлению с независимым развитием.

**Преимущества:**
- **Ускорение вывода продуктов**: Финтех и AI развиваются независимо, без координации изменений в DWH
- **Снижение зависимости от DWH**: Каждый домен имеет свой Data Product, изменения в одном домене не влияют на другие
- **Отдельное развитие направлений**: Новые партнёры (фармацевтика, электроника) добавляются как новые домены без изменения существующих

## Потоки данных между доменами

- **События через Event Bus**: Асинхронная интеграция, слабая связанность
- **Data Products в Data Lakehouse**: Каждый домен предоставляет свои витрины
- **Аналитический домен**: Агрегирует данные из всех доменов для отчётности
