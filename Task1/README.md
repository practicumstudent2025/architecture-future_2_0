# Задание 1: Проектирование целевой архитектуры и приоритизация проблем

## Структура решения

### 1. `future_2_0_c4_task1.drawio`
Диаграмма контейнеров в модели C4, показывающая целевую архитектуру системы «Будущее 2.0» через год. 

**Ключевые особенности:**
- Облачная мульти-доменная платформа
- Портал самообслуживания (витрина данных)
- Доменная архитектура (Финтех, Клиники, AI, Головной офис)
- Event Bus для интеграции
- Аннотации, показывающие поддержку бизнес-сценариев

**Поддержка бизнес-сценариев (отмечено на диаграмме):**
- 🚀 **Быстрая подготовка отчётности**: Портал → BI → Semantic → Lakehouse (VITRINES)
- 🔄 **Независимое развитие**: Финтех и AI домены изолированы, Event Bus для слабой связанности
- 📈 **Масштабирование для новых бизнесов**: Легко добавлять новые домены, стандартизированная интеграция

### 2. `business_scenarios_support.md`
Детальное описание того, как целевая архитектура поддерживает ключевые бизнес-сценарии:
- Быстрая подготовка отчётности
- Независимое развитие финтех- и ИИ-направлений
- Масштабирование для новых бизнесов

### 3. `problem_analysis.md`
Анализ проблемных мест текущей архитектуры:
- Описание 8 проблемных мест
- Влияние каждой проблемы на бизнес-сценарии
- Технические последствия
- Сводная таблица проблем

### 4. `prioritization.md`
Приоритизация выявленных проблем с использованием:
- **Матрицы Эйзенхауэра** (важность/срочность)
- **Метода MoSCoW** (Must/Should/Could/Won't)
- Связь приоритизации с целями бизнеса
- Рекомендации по решению по фазам

## Ключевые результаты

### Целевая архитектура
- **Data Mesh подход**: доменная ориентация с независимым развитием направлений
- **Портал самообслуживания**: витрина данных для бизнес-пользователей
- **Event-Driven Integration**: асинхронная интеграция через события
- **Облачная инфраструктура**: масштабируемость и надёжность

### Приоритизированные проблемы
1. **Критично**: Низкая производительность аналитических запросов, отсутствие доменной изоляции
2. **Важно**: Монолитная архитектура DWH, отсутствие витрины данных
3. **Желательно**: Устаревшие технологии, сложная интеграция
4. **Вспомогательно**: Отсутствие Data Catalog, неэффективное использование ресурсов

### Связь с целями бизнеса
- **Выручка**: Решение проблем производительности ускорит принятие управленческих решений
- **Time-to-market**: Доменная архитектура ускорит вывод новых продуктов
- **Качество сервисов**: Доменная изоляция обеспечит соответствие регуляторам
