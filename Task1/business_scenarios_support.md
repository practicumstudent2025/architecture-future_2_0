# Поддержка ключевых бизнес-сценариев целевой архитектурой

## Таблица поддержки бизнес-сценариев

| Бизнес-сценарий | Ключевые компоненты архитектуры | Результат |
|----------------|--------------------------------|-----------|
| **Быстрая подготовка отчётности** | Портал самообслуживания → BI → Semantic Layer → Data Lakehouse (VITRINES) | Время формирования отчётов: **часы → минуты/секунды** |
| **Независимое развитие финтех- и ИИ-направлений** | Доменная архитектура (изолированные домены) + Event Bus (слабая связанность) + Data Products | Финтех и AI направления развиваются независимо, без влияния друг на друга |
| **Масштабирование для новых бизнесов** | Доменная платформа + Event Bus (стандартизированная интеграция) + Self-Serve Platform | Новые направления (фармацевтические компании, производитель оборудования) интегрируются быстро без изменения существующей архитектуры |
