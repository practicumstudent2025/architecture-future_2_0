DWH на базе Microsoft SQL Server 2008. Устаревшая технология, не масштабируется. Содержит значительную часть бизнес-логики.

**Бизнес-сценарии:** Централизованная отчётность, консолидированная аналитика. Планируется миграция на Data Lakehouse для масштабирования отчётности.
