# Технический радар Будущее 2.0

## Установка

```bash
npm install
```

## Запуск

```bash
npm run build
npm run serve
```

Откройте http://localhost:3000

## Структура

- `radar/` - директории с версиями радара (по датам)
- `public/` - статические файлы (логотип, изображения)
- `config.json` - настройки радара
