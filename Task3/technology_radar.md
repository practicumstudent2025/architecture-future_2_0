# Технический радар

## Adopt (Внедряем)

| Технология/Методология | Описание | Бизнес-сценарии |
|------------------------|----------|----------------|
| **Облачная инфраструктура** | AWS/Azure/GCP для размещения всех сервисов | Масштабирование отчётности, независимое развитие доменов, снижение затрат |
| **Data Mesh** | Доменная архитектура данных | Интеграция новых бизнесов, независимое развитие финтех и AI |
| **Event Bus (Kafka/Pulsar)** | Асинхронная интеграция через события | Независимое развитие доменов, real-time обработка |
| **Data Lakehouse** | Единое хранилище RAW/CURATED/VITRINES | Быстрая подготовка отчётности, консолидированная аналитика |
| **Data Catalog** | Каталог данных с lineage | Поиск данных для портала самообслуживания, управление доступом |
| **IAM/SSO** | Единая система доступа | Безопасность медицинских и финансовых данных, соответствие регуляторам |

## Trial (Пробуем)

| Технология/Методология | Описание | Бизнес-сценарии |
|------------------------|----------|----------------|
| **Self-service BI** | Портал самообслуживания для бизнес-пользователей | Быстрая подготовка отчётности, снижение нагрузки на IT |
| **Semantic Layer** | Слой метрик и бизнес-логики | Стандартизация отчётов, ускорение создания дашбордов |
| **Data Quality платформа** | Автоматические проверки качества данных | Поддержание качества медицинских и финансовых сервисов |
| **ELT вместо ETL** | Загрузка перед трансформацией | Ускорение загрузки данных, гибкость трансформаций |

## Assess (Оцениваем)

| Технология/Методология | Описание | Бизнес-сценарии |
|------------------------|----------|----------------|
| **Streaming Analytics** | Real-time обработка событий | Мгновенная реакция на события в финтехе и клиниках |
| **MLOps платформа** | Управление ML моделями | Масштабирование AI-сервисов, автоматизация обучения моделей |
| **GraphQL для данных** | Гибкий API для запросов | Упрощение интеграции между доменами |

## Hold (Не используем)

| Технология/Методология | Причина |
|------------------------|---------|
| **Legacy DWH (SQL Server 2008)** | Устаревшая технология, не масштабируется |
| **PowerBuilder** | Устаревший UI, нет поддержки облачных решений |
| **Apache Camel ESB** | Монолитная интеграция, заменяем на Event Bus |
