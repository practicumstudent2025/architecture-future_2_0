# Роадмап изменений

## Этап 1: Подготовка инфраструктуры (2-3 месяца)

**Бизнес-цель:** Создать основу для миграции в облако

**Шаги:**
- Развёртывание облачной инфраструктуры (AWS/Azure)
- Настройка IAM/SSO для единого доступа
- Развёртывание Event Bus (Kafka)
- Создание Data Lakehouse (RAW слой)

**Ожидаемые результаты:**
- Облачная инфраструктура готова к миграции
- Единая система доступа работает
- Event Bus принимает события от доменов

**Ответственные:** Platform Team, Security Team

**Ресурсы:** 2-3 DevOps инженера, 1 Security специалист

---

## Этап 2: Миграция доменов (4-6 месяцев)

**Бизнес-цель:** Независимое развитие финтех и AI направлений

**Шаги:**
- Миграция Финтех домена в облако
- Миграция AI домена в облако
- Создание доменных Data Products
- Интеграция через Event Bus

**Ожидаемые результаты:**
- Финтех и AI работают независимо
- События публикуются в Event Bus
- Доменные витрины созданы

**Ответственные:** Финтех команда, AI команда, Data Engineers

**Ресурсы:** 3-4 разработчика на домен, 2 Data Engineer

---

## Этап 3: Data Lakehouse и ETL (3-4 месяца)

**Бизнес-цель:** Быстрая подготовка отчётности

**Шаги:**
- Создание CURATED и VITRINES слоёв
- Настройка ELT пайплайнов
- Внедрение Data Quality проверок
- Интеграция с Data Catalog

**Ожидаемые результаты:**
- Витрины данных готовы для аналитики
- Автоматические проверки качества работают
- Данные каталогизированы

**Ответственные:** Data Engineering Team

**Ресурсы:** 3-4 Data Engineer, 1 Data Quality специалист

---

## Этап 4: Портал самообслуживания (3-4 месяца)

**Бизнес-цель:** Сотрудники могут создавать отчёты самостоятельно

**Шаги:**
- Разработка Semantic Layer (метрики)
- Создание портала самообслуживания
- Интеграция с Data Catalog для поиска
- Настройка доступа через IAM/SSO

**Ожидаемые результаты:**
- Портал доступен бизнес-пользователям
- Пользователи могут создавать свои отчёты
- Поиск данных через каталог работает

**Ответственные:** BI Team, Frontend Team

**Ресурсы:** 2-3 Frontend разработчика, 2 BI специалиста, 1 UX дизайнер

---

## Этап 5: Миграция медицинского домена (2-3 месяца)

**Бизнес-цель:** Поддержание качества медицинских сервисов

**Шаги:**
- Миграция медицинского домена
- Изоляция медицинских данных
- Настройка аудита и логирования
- Соответствие медицинским регуляторам

**Ожидаемые результаты:**
- Медицинский домен в облаке
- Данные изолированы и защищены
- Аудит настроен

**Ответственные:** Медицинская команда, Security Team, Compliance

**Ресурсы:** 2-3 разработчика, 1 Security специалист, 1 Compliance специалист

---

## Этап 6: Интеграция новых бизнесов (ongoing)

**Бизнес-цель:** Масштабирование для новых партнёров

**Шаги:**
- Добавление нового домена (фармацевтика/электроника)
- Стандартизированная интеграция через Event Bus
- Автоматическая регистрация в Data Catalog

**Ожидаемые результаты:**
- Новый домен интегрирован
- Данные доступны в портале

**Ответственные:** Platform Team, новый домен команда

**Ресурсы:** 2-3 разработчика на новый домен
